# 任务监控和停止状态修复计划

目标：修复正常连线被判定卡死，以及停止任务后开始按钮持续禁用的问题。

实现方式：在当前任务控制器上接收成功输入事件，更新活动及回调时间，保留节点级重复点击检测。停止流程使用可等待的异步操作和统一收尾，覆盖重复停止、提前返回、取消及异常。

技术：.NET 10、Avalonia、MaaFramework Binding、xUnit。

约束：保留现有界面改动；不改游戏策略和 Python 资源；不把截图计入输入活动；不启动实际游戏操作。当前分支为 codex/map-home-layout，在当前目录修复以便更新用户指定的本地发布目录。

需要核对：控制器更换后不接收旧控制器活动；失败输入不刷新活动时间；截图不能掩盖无输入；重复停止不能提前解锁；异步停止异常不能跳过收尾。
